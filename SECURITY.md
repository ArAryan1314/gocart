# Security Policy

This repository is a fork of [GreatStackDev/gocart](https://github.com/GreatStackDev/gocart).

- Vulnerabilities in the **original project**: please report them upstream, following the policy at <https://github.com/GreatStackDev/gocart/security>.
- Issues specific to **this fork** (CI, configuration, changes made here): open a private advisory via the **Security** tab of this repository.
